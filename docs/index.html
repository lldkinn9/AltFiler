アプリ概要・主な特徴

AltFiler は、iOS標準の「ファイル」や「写真」アプリとは完全に切り離された独立ローカル領域で大切なファイルを整理・保護し、動画・音声・画像・PDFを快適に再生・閲覧できるオールインワンアプリです。

  • 完全独立ファイル管理＆ステルスロック：Face ID / Touch ID および iOS Keychain (SHA-256) 暗号化によるフォルダ保護・アプリ起動時ロック・バックグラウンド覗き見防止シールドを搭載。
  • 高機能メディアプレイヤー：押している間だけ2.0倍速再生、ピンチズーム拡大（最大4.0倍）＆パン移動、ダブルタップ10秒スキップ、Picture-in-Picture (PiP)、再生位置を記憶するクリップ機能、バックグラウンド再生＆ロック画面連携に対応。
  • ZIP圧縮・解凍＆マルチインポート：写真ライブラリ、ファイルアプリ、共有シートからの一括取り込み、およびアプリ単体でのZIP圧縮・解凍に完全対応。

プライバシーポリシー (Privacy Policy)

1. ファイル・データの100%ローカル保存

「AltFiler」（以下「本アプリ」）内に取り込まれたすべてのファイル、フォルダ、お気に入り設定、クリップ情報、および認証設定は、お客様のデバイス（iPhone / iPad）内の独立したローカルストレージおよび iOS Keychain 内にのみ保存され、保存されたファイルや閲覧履歴・検索履歴が外部サーバーへ送信・収集されることは一切ありません。

2. 広告配信およびトラッキング許可（ATT）について

本アプリの無料版では、アプリ運営維持のため画面下部に第三者配信の広告サービス（Google AdMob）によるバナー広告を表示する場合があります。iOS の App Tracking Transparency（ATT）ダイアログでお客様が許可された場合に限り、最適な広告配信のために広告識別子（IDFA）が利用されます。許可しない場合でも本アプリの全機能をご利用いただけます。また、アプリ内課金「AltFiler Pro（広告非表示）」をご購入いただいた場合、広告表示および広告SDKによる通信は完全に停止されます。

3. 生体認証（Face ID / Touch ID）およびパスワード情報の取り扱い

本アプリのロック機能で使用するマスターパスワードは、iOS標準の CryptoKit（SHA-256）により不可逆ハッシュ化された上で iOS Keychain のセキュア領域にのみ格納されます。また、Face ID / Touch ID による生体認証は Apple 標準の LocalAuthentication フレームワークを介してOSレベルで処理され、本アプリが生体データそのものにアクセス・保存することはありません。

4. 写真ライブラリ・ファイルへのアクセス権限

お客様が明示的に「写真・動画を取り込む」または「外部ファイルを取り込む」を選択した場合に限り、選択されたメディアや書類を本アプリ内へコピーするためにのみアクセスします。
